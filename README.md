# Field Notes

A draggable collage of paintings, outdoor photos and favorites for the Play page on [anderscarlson.co](https://anderscarlson.co).

- `index.html` is the collage. The background is transparent so it sits on any page color.
- Edit titles, captions and starting positions in the `NOTES` list near the bottom of `index.html`.
- Images live next to it in this folder.

To use it in Framer, enable GitHub Pages for this repo and point an Embed (URL) at the Pages address.
